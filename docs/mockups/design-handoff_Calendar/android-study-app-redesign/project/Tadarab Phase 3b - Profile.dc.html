Demo student
Jumps the profile between four point totals so you can see each tier's colour carry through the rank card, its bar and the Ranks list.
Try these paths
Edit Profile: Save is dead until the name actually changes, and refuses an empty field with a stated reason. Study Reminder: with no time set the helper reads as a prompt and Save stays dead; pick a time and both come alive. Turn the toggle off and Save re-enables — switching the reminder off is itself a change worth saving. View Ranks from the progress card: completed tiers read 100%, the current one carries the badge and its own bar, locked ones sit at 0%. Log Out asks first, then shows where the app would land.
Rules
Rank — derived from total points, never stored separately; the bar measures progress inside the current tier. Edit Profile — name only for now; email and password are deliberately out of scope. Save — disabled while the draft equals the saved value, so the button always means something.
