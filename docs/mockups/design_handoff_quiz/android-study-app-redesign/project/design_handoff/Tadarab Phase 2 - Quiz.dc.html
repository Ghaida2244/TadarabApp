Try these paths
Start new quiz → raise the count above what one lecture holds → the limit dialog appears before any question does. Pick Exam Mode: the close button is gone, Previous is dead on question one, Next stays pink until you choose an option, and the last question turns Next into Submit. Pick Learning Mode: Submit is dead until you pick; after it, the answer, the reason and the slide appear and the button becomes Next Question. Leave a Learning session through the X — it saves into the same session and resumes at the same question; answering more and leaving again updates that one session, it never makes a second. Practice the weak ones after a Learning summary: the X leaves straight away with no save prompt — practice is never tracked, so it always starts over.
Button rules
Disabled — pink fill for a red action, grey outline for a secondary one; never hidden, so the student can see what's coming. Exam Mode — no close, no system back, no exit sheet. The only way out is Submit. Points — 4 per correct answer, shown on the summary and added to the streak. Review Mistakes — Exam Mode only, and only when something was wrong.
