Try these paths
Step forward a month — no dots, and the empty state appears under the grid; today's ring only shows on the real month. Hit the grid icon in the header for the year view — twelve mini-months, today filled red, event days tinted with their colours beneath. Tap any month to open it in the detailed view. The grid button in the header is the only way to jump freely; "Back to today" appears whenever you are off the current month. Past months work exactly like future ones — pick a date that has already been and the event saves and lists normally. Only the reminder is time-checked. Tap a dotted day → its sheet lists each event with the course colour; delete goes through the confirm and the dot disappears with it. Add Event: Save is dead with a stated reason until name, date and time are all filled. Pick a course — the swatch row disappears and the event inherits that course's colour. Set the date to today and push the reminder to weeks: the value is refused and the field turns red, because that moment has already passed.
Rules
Colour — a linked course owns it; the manual picker only exists when no course is linked. Reminder — validated live against date + time on every change; an invalid value is rejected, not accepted-then-warned. Delete — removes the event and cancels its scheduled notification.
