Color usage
#0B0F5B — Deep blue Header field, bottom nav, the resume block, poster statements, all headings and body text, secondary buttons, rank bar fill.
#E31B23 — Red Primary action only, plus small emphasis: active nav bar, step numbers, streak squares, progress fills, "today" and "see all", point badges. Never for paragraph text.
#FFFFFF — White The whole content ground and the sheet — no gray cards, no shadows. Type on the navy fields.
#9CA3AF — Gray Kept for decoration only — inactive streak marks and unfilled tracks. All small metadata (overlines, timestamps, course codes, file hints) is set in muted navy #6B7080 so 10–12px type stays readable.
Navy 40% / 12% — Rules 2px rules do the organising: 40% under section heads, 12% between rows and grid cells. These replace every card, border-radius and shadow in the old screens.
What changed
  • The empty state now welcomes and guides: poster statement, a numbered 3-step setup, one obvious red action.
  • Today's progress became a modular 3-cell grid — bigger numbers, no floating card.
  • Streak, rank progress and mastery bars carry the gamification without badges or mascots.
  • Resume-session block puts the unfinished quiz above events — one tap back into studying.
  • Nav labels are set in Archivo instead of icons, so the chrome matches the type system.
