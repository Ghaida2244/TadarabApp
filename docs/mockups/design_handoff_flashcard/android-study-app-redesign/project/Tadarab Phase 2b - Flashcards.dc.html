Try these paths
Start new flashcards → untick every material and Generate goes dead with a reason; tick one and it comes back. Aim for more cards than the material holds → the limit dialog appears before the first card. Tap a card to flip it: the answer and its source appear, and only then do Need review / I know it exist. Leave mid-deck through the X — it saves into the same session and resumes on the same card; it never makes a second session. Finish, then Review now — that pass is untracked, navigates with Previous / Next, and its X exits immediately with no save prompt.
Rules
One mode only — no Exam / Learning split anywhere in this flow. Verdict buttons — rendered only on a flipped card, never before; they advance the deck and record the mark. Points — 2 per card marked "I know it", added to the home streak. Review now — only offered when something was marked for review.
