Phase 1 covers
Home empty · home with a session in progress · home with nothing in progress (course picker) · create course · upload material (with AI read) · courses empty · courses list · course detail with study tools and materials · duplicate-name error · delete confirmation.
New patterns introduced here
Course colour — 48px rounded square with initials, filled with the colour chosen for that course: four available presets or any colour from the picker. Curved header — detail screens get a solid block in the course's own colour with a 28px bottom curve, back and delete as 40px circles. Study tools — two equal tiles, navy tint for Quiz and red tint for Flashcards, so the pair reads as a choice. Destructive dialog — centred card, red icon chip, red confirm, neutral "Keep it" below. Never a red button on the safe option. Inline error — red tint strip under the field, shakes once on submit.
